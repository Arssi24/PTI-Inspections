Fleet walkaround & inspection app

Real accounts, backed by Supabase. Fleet managers get a fleet code on sign-up — share it with your drivers so their submissions link to your dashboard.

Pick this if you're setting up a brand-new company. A new fleet code and a manager security code are created automatically for you. Give drivers only the fleet code.

Joining an existing fleet takes both codes. Drivers only need the fleet code, so never share the manager security code with them.

Another manager can show you this code on their dashboard.
